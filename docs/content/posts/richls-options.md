このページでは、`richls` のコマンドラインオプションを一覧で説明します。

## 構文

```bash
richls [OPTIONS] [FILE]
```

`[FILE]` は、一覧表示の対象となるファイルまたはディレクトリです。
省略した場合は、カレントディレクトリを対象にします。

## 引数

| 引数 | 説明 |
| --- | --- |
| `[FILE]` | 表示対象のパスです。ファイルまたはディレクトリを指定できます。省略時は `.` を対象にします。 |

## オプション一覧

| オプション | 説明 |
| --- | --- |
| `-l`, `--long` | 詳細表示モードで出力します。ファイルサイズ、更新日時、権限などのメタ情報を表示します。 |
| `-a`, `--all` | 隠しファイルを表示します。 |
| `--humanize` | ファイルサイズを KB / MB / GB などの人間が読みやすい形式で表示します。現行実装では詳細表示を有効にする互換オプションです。 |
| `--tagline` | ディレクトリ内に `README.md` が存在する場合、その概要や先頭行を表示します。現行実装では詳細表示を有効にする互換オプションです。 |
| `--pdf-title` | PDF ファイルに埋め込まれたタイトルを表示します。現行実装では詳細表示を有効にする互換オプションです。 |
| `--respect-ignore` | `.gitignore` や `.dockerignore` を考慮し、該当するファイルやディレクトリを除外します。 |
| `--new-mark` | 24時間以内に作成されたファイルに `"new"` を付与して表示します。現行実装では詳細表示を有効にする互換オプションです。 |
| `--sort <key>` | 指定された基準で出力順を変更します。利用可能な値は `name`, `size`, `mtime` です。 |
| `-h`, `--help` | ヘルプを表示します。 |
| `-V`, `--version` | バージョンを表示します。 |

## ソートキー

| キー | 並び替え基準 |
| --- | --- |
| `name` | ファイル名またはディレクトリ名 |
| `size` | ファイルサイズ |
| `mtime` | 更新日時 |

`--sort` は、次のように指定できます。

```bash
richls --sort name
richls --sort=size
```

## 詳細表示で含まれる情報

`-l` または `--long` を指定した場合、出力には次のような情報が含まれます。

- ファイル種別や権限を含むモード情報
- リンク数
- 所有者
- グループ
- ファイルサイズ
- 更新日時
- ファイル名またはディレクトリ名
- README や PDF から取得した補助情報

## ignore ファイルの扱い

`--respect-ignore` を指定した場合、`richls` は対象ディレクトリの `.gitignore` や `.dockerignore` を参照します。
これにより、リポジトリで通常無視されるビルド成果物、依存パッケージ、キャッシュなどを一覧から除外できます。

## 新規ファイルの判定

`--new-mark` を指定した場合、24時間以内に作成されたファイルに `"new"` が表示されます。
直近で追加されたファイルの確認や、作業後の差分確認に利用できます。
