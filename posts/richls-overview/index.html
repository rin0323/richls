    richls Overview

    richls の目的、特徴、基本的な使いどころを紹介します。

    richls は、標準的な ls コマンドを拡張したファイル一覧表示ツールです。 ファイル名やディレクトリ構造だけでなく、サイズ、更新日時、README の概要、PDF のタイトル、新しく作成されたファイルの印などを表示し、ディレクトリの中身を短時間で理解しやすくします。

    何を解決するか#

    通常の ls は軽くて便利ですが、プロジェクトの構造やファイルの意味までは分かりません。 たとえば、複数のサブディレクトリが並ぶリポジトリでは、名前だけを見ても各ディレクトリの役割が分かりにくいことがあります。

    richls は、一覧表示に少しだけ文脈を足します。 README の先頭行、PDF に埋め込まれたタイトル、24時間以内に作成されたファイルの "new" 表示などを組み合わせることで、単なるファイル一覧を「読める一覧」にします。

    主な特徴#

    • ファイルまたはディレクトリのパスを受け取り、対象の一覧を表示します。
    • パスを省略した場合は、カレントディレクトリを対象にします。
    • -l / --long で、ファイルサイズ、更新日時、メタ情報を含む詳細表示に切り替えます。
    • --humanize で、ファイルサイズを KB / MB / GB などの読みやすい形式で表示します。
    • --tagline で、ディレクトリ内の README.md から概要や先頭行を表示します。
    • --pdf-title で、PDF ファイルに埋め込まれたタイトルを表示します。
    • --respect-ignore で、.gitignore や .dockerignore に従って不要な項目を除外します。
    • --new-mark で、24時間以内に作成されたファイルに "new" を付与します。
    • --sort name|size|mtime で、名前、サイズ、更新日時に基づいて並び替えます。

    基本構文#

    richls [OPTIONS] [FILE]

    [FILE] には、表示対象のファイルまたはディレクトリを指定します。 省略した場合は、現在のディレクトリを表示します。

    代表的な使いどころ#

    プロジェクトの全体像を把握したい場合は、README の概要と ignore ファイルの反映を組み合わせます。

    richls --tagline --respect-ignore .

    最近追加されたファイルを確認したい場合は、新規マークと更新日時順のソートを組み合わせます。

    richls --new-mark --sort mtime .

    PDF や資料が多いディレクトリでは、PDF タイトルの表示が役立ちます。

    richls --pdf-title ./docs

    設計方針#

    richls は、入力されたパスに基づいてファイル一覧を取得し、指定されたオプションに応じて情報を加工し、標準出力へテキスト形式で出力します。 既存の ls の使い勝手を保ちながら、プロジェクト把握、新規ファイル確認、資料確認、不要ファイルを除いた一覧確認をしやすくすることを目的としています。
